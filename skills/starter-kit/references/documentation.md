# Documentation Standards Reference

Referência de regras gerais: [`../../../rules.md`](../../../rules.md).

`README.md` descreve o quê, por quê, como rodar, como testar. Máximo 60 linhas.

`ARCHITECTURE.md` descreve mapa de domínios, fluxo de dados e fronteiras.

`docs/adr/NNNN-<slug>.md` registra decisões difíceis de reverter.

Ciclo de vida do ADR: `proposed`, `accepted`, `superseded by NNNN`. Nunca delete um ADR.
