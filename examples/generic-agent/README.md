# Exemplo: Workspace Agente Genérico

Este exemplo demonstra um workspace portátil gerado com o adaptador genérico.

```text
examples/generic-agent/

├── .agents/
│   ├── skills/

│   ├── subagents/
│   │   └── generic-worker.md
│   └── memory/
│       └── index.md

    └── architecture.md
```
