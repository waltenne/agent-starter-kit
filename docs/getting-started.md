# Guia de Início Rápido (Getting Started)

Este guia apresenta os conceitos fundamentais do agent-starter-kit em linguagem simples.

---

## O que é um Agente de IA

Um agente de IA é um assistente de código capaz de ler arquivos, executar comandos e auxiliar na construção de projetos. Ele segue instruções escritas em Markdown para entender como trabalhar no seu repositório.

---

## O que é um Workspace

Um workspace é o diretório configurado onde seu projeto reside, contendo código fonte, testes e documentação. Ele possui um arquivo central de regras que orienta o comportamento da IA.

---

## O que é uma Skill

Uma skill é um procedimento reutilizável e específico para realizar uma tarefa recorrente. Ela possui entrada, passos definidos e saída previsível.

---

## O que é um Subagente

Um subagente é uma instância especializada da IA delegada para resolver um problema isolado. Ele possui escopo delimitado e não altera regras do sistema principal.

---

## O que é um Blueprint

Um blueprint é um guia de decisões de arquitetura para um domínio específico, como desenvolvimento web ou dados. Ele sugere estruturas e verificações ideais para o projeto.
